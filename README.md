# 晨光跳跃 · Dawn Leap

一款用 **Python + pygame** 写的 2D 像素平台跳跃游戏。

**所有美术和音效都是代码现场生成的** —— 没有任何图片文件、没有任何音频文件，
连背景音乐都是用方波/三角波合成出来的 8 小节循环芯片音乐。
整个项目只有 `.py` 文件。

## 快速开始

### Windows（最简单）

双击 **`play.bat`**（或右键 `play.ps1` → 使用 PowerShell 运行）。
它会自动找 Python、缺 pygame 就装、然后启动游戏。

### 手动运行

```bash
pip install -r requirements.txt
python main.py
```

### 首次安装（推荐用虚拟环境）

```powershell
# Windows PowerShell
./setup.ps1
.\.venv\Scripts\python.exe main.py
```

```bash
# macOS / Linux
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

### 命令行参数

| 参数 | 说明 |
| --- | --- |
| `--level N` | 直接进入第 N 关（1/2/3） |
| `--no-audio` | 关掉所有声音 |
| `--profile N` | 跑 N 帧后自动退出并打印性能，用于测试 |

## 操作

| 按键 | 功能 |
| --- | --- |
| `←` `→` / `A` `D` | 左右移动 |
| `空格` / `↑` / `W` | 跳跃（**空中再按一次 = 二段跳**） |
| `P` | 暂停 / 继续 |
| `R` | 重开本关 |
| `Q` | 结算画面返回主菜单 |
| `M` | 静音开关 |
| `F11` | 全屏切换 |
| `F3` | 显示帧率 |
| `ESC` | 暂停 / 返回主菜单 |

**跳跃手感细节**（这些是平台游戏好不好玩的关键）：

- **可变跳跃高度**：轻点跳得矮，按住跳得高
- **土狼时间**：跑出平台边缘后 0.1 秒内仍能起跳，不会「明明还在边上却跳不起来」
- **跳跃缓冲**：落地前 0.12 秒按跳会被记住，落地瞬间自动起跳
- **二段跳**：空中再按一次

## 玩法

- **目标**：走到关卡尽头那扇发光的门（`G`）即通关，一共 3 关。
- **生命**：每关 3 颗心。碰到尖刺、冰晶、敌人侧面会掉 1 颗心，掉光就 Game Over。
- **得分**：
  - 金币 +10、宝石 +100（宝石都在难拿的高处）
  - 踩敌人 +200
  - 回血爱心恢复 1 颗心并 +20
  - 通关时按剩余生命和用时给奖励，并给出 S / A / B / C 评价
- **敌人**：
  - 绿史莱姆：定时朝玩家跳过来，**从上方踩**
  - 紫蝙蝠：在空中缓慢追踪玩家，**从上方踩**
  - 橙刺壳虫：直线巡逻，会自己避开尖刺，**从上方踩**
  - 从侧面撞到任何敌人都会掉血
- **机关**：
  - `?` 金币砖：从下面顶一下会蹦出金币（顶过之后变成灰砖）
  - 弹簧：踩上去弹得很高
  - 移动平台：会横着往返，站上去会被带着走
  - 梯子：按 `↑` / `↓` 抓住上下移动
  - 尖刺 / 冰晶：碰到掉血
  - 洞窟地图顶部有阴影，掉进坑里直接重来

**新手提示**：掉进坑、被敌人打死，从关卡开头满血重来（已经吃过的东西不会回来）；
按 `R` 可以把整关重置，金币砖也全部恢复。

## 关卡

| # | 名称 | 主题 | 特点 |
| --- | --- | --- | --- |
| 1 | 晨光草原 Dawn Meadow | 黎明草原 | 教学关：跳坑、顶金币砖、踩敌人、弹簧 |
| 2 | 幽暗洞窟 Gloom Cavern | 地下洞窟 | 梯子、上下两层、尖刺密集 |
| 3 | 夜空高塔 Night Tower | 夜空高塔 | 移动平台、云朵平台、大量二段跳 |

关卡设计遵循一个「跳跃预算」：跑速 118 px/s、起跳初速 -232 px/s、重力 900 px/s²，
算下来单跳高度约 2 格、单跳水平距离约 3.5 格，二段跳约 5 格高 / 7 格远。
所以所有平台间距都控制在这些数字以内。

## 项目结构

```
game/
├── main.py        # 入口，命令行参数
├── game.py        # 主循环、状态机、输入、计分、摄像机
├── world.py       # 关卡解析、瓦片物理、视差背景、地面渲染、机关
├── entities.py    # 玩家物理、敌人 AI、收集品、粒子
├── levels.py      # 三个关卡的地图数据（网格坐标定义）
├── art.py         # 程序化像素美术：字符画 + 调色板 -> 贴图图集
├── audio.py       # 程序化音效与背景音乐（波形合成）
├── ui.py          # 字体、HUD、菜单、结算画面
├── settings.py    # 所有可调参数（手感、配色、主题）
├── tools/
│   ├── smoke_test.py   # 无头自测：关卡校验 + 自动试玩 + 性能
│   └── screenshot.py   # 批量截图，用于肉眼验收
├── play.bat / play.ps1 # 一键启动
└── setup.ps1           # 创建虚拟环境并安装依赖
```

### 代码里的几个设计点

- **整数倍缩放**：内部逻辑分辨率固定 480×270，输出时按整数倍放大（默认 3 倍 = 1440×810），
  所以像素永远锐利、不会有半像素模糊；窗口大小不是整数倍时自动加黑边居中。
- **固定时间步**：物理固定 60 Hz、渲染帧率浮动，慢机器上手感不会变。
- **贴图自动对齐**：角色的碰撞盒比贴图小（10×14 vs 12×24），绘制时按「非透明像素包围盒」
  把脚底对齐到碰撞盒底部，跑动/跳跃时不会出现悬空或陷进地面的错位。
- **音频降级**：没有声卡时会静音继续跑，不会崩。

## 想改点什么？

| 想改的东西 | 去哪儿改 |
| --- | --- |
| 跳跃高度、跑速、重力 | `settings.py` 的「物理」段 |
| 配色、天空、远景 | `settings.py` 的 `THEMES` |
| 角色 / 砖块 / 敌人长什么样 | `art.py` 里的字符画（`.=透明`，字母=调色板颜色） |
| 音效、背景音乐 | `audio.py` 里的 `_sfx_*` 和 `_track` |
| 关卡地形、物品、敌人位置 | `levels.py`，用 `Canvas` 的 `rect` / `plat` / `coins` 摆放 |

比如想加一块平台，就在 `_level1()` 里加一行：

```python
c.plat(52, 58, 7, "B")     # 从第 52 列到第 58 列，第 7 行，红砖
```

改完跑一下自测，确认关卡数据没问题：

```bash
python tools/smoke_test.py
```

它会检查：行宽是否一致、出生点有没有卡在方块里、终点门下面有没有地面、
敌人和收集品有没有生成在墙里、自动机器人能不能通关、以及每帧渲染耗时。

## 环境要求

- Python **3.9+**（开发验证于 3.12）
- pygame **2.5+**（开发验证于 2.6.1）

只依赖 pygame 一个第三方库。窗口标题栏、图标、全屏都由 pygame/SDL 提供。
